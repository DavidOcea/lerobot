## 简介

这个其实和本代码哭自带的hil挺像的，hil的主体policy是sac/modeling_sac，后续如果需要替换sac的动作模块策略可以修改sac的actor即可。

## 使用

使用非常简单，其实核心就是modeling_act_ppo中的 select_action ，这部分其实和原本的act就多了强化逻辑，将生成的动作通过ppo逻辑计算强化损失，从而更新act的参数实现在线训练。其实直接将这部分逻辑写在act中就能无缝衔接，这里分开写是为了便于修改阅读。

这个逻辑适用于现有的所有策略。

使用上，策略模型可以和以前一样训练，ppo训练只需要推理模型即可实现在线优化。
