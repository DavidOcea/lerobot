## 1. 准备工作

### 1.1 硬件准备
- 机器人已通电并正常工作
- 相机已连接（检查USB连接）
- 工件和卡槽已放置在合适位置
- **示教器** 已连接（用于标定时的关节移动）

### 1.2 标记贴纸准备

**重要**: 标记贴纸是系统识别工件和卡槽位置的关键！

| 标记类型 | 颜色 | 数量 | 放置位置 |
|---------|------|------|---------|
| 工件标记 | 绿色 | **3个** | 贴在工件上，呈三角形分布，不能被夹爪遮挡 |
| 卡槽标记 | 红色 | **3个** | 贴在卡槽上，呈三角形分布，靠近定位销 |

**标记要求**:
- 直径约 **1.5-2 厘米** (系统默认15mm)
- 颜色要鲜明、对比度高
- 贴纸要平整，不要起皱
- 三个同色标记呈三角形分布，间距 2-5 cm

### 1.3 ChArUco标定板（手眼标定用）

**新手建议使用手眼标定方法，更简单、精度更高！**

生成标定板：
```bash
cd /home/smai/dc_dir/lerobot
python -m precision_place.calibration.hand_eye
```

打印生成的 `charuco_board.png`：
- **不要缩放**，保持原始尺寸
- 打印后固定在工作台上
- 标定过程中**绝对不能移动**

### 1.4 光照条件
- 确保工作区域光线充足
- 避免强光直射（会产生反光）
- 避免阴影遮挡标记

## 2. 启动系统

### 2.1 启动示教程序（推荐）

**重要**: 标定时需要移动机器人关节，推荐使用示教模式。

```bash

cd /home/smai/dc_dir
./run.sh
```

等待示教程序启动完成，看到以下信息后示教器即可控制机器人：
```
✓ 机器人状态共享已启用 (标定程序可读取)
```

### 2.2 启动精准放置程序

```bash
# 终端2：启动精准放置程序
cd /home/smai/dc_dir/lerobot
python precision_place/run.py
```

### 2.3 首次运行提示
如果是首次运行，系统会显示欢迎引导界面，按 **Enter** 继续。

## 3. 连接设备

### 3.1 选择连接
在主菜单选择 **1** 连接设备

### 3.2 选择手臂
```
选择手臂:
  1. 右手 (默认)
  2. 左手
```
输入 **1** 或 **2** 选择要使用的手臂

### 3.3 选择模式
```
连接模式:
  1. 独立模式 (默认) - 直接控制机器人
  2. 示教模式 - 与示教系统协同，只读取状态
```

**推荐选择 2（示教模式）**，这样可以用示教器移动机器人进行标定。

## 4. 测试检测

### 4.1 进入测试
主菜单选择 **3** 测试检测

### 4.2 检查画面
确认能看到标记：
- 工件标记显示为**绿色圆圈**
- 卡槽标记显示为**红色圆圈**

- 确保画面中显示 **至少 1+1 个标记**
- 标记检测框稳定不跳动
- 按 **q** 键退出测试

## 5. 手眼标定（推荐）

**手眼标定是最简单、精度最高的方法！**

### 5.1 为什么选择手眼标定？

| 对比项 | 手眼标定 | 传统标定 |
|-------|---------|---------|
| 标定次数 | **一次** | 多次（每个关节、每个高度） |
| 精度 | 数学精确 | 依赖经验 |
| 透视补偿 | 自动处理 | 手动设置 |
| 验证 | RMSE自动验证 | 无 |

### 5.2 标定步骤

#### 步骤1：进入手眼标定
```
主菜单 → 4. 标定 → H. 手眼标定
```

#### 步骤2：输入URDF路径
系统提示输入URDF文件路径：
```
请输入URDF文件路径: /path/to/robot.urdf
```
（URDF文件用于计算正运动学，只需在标定时提供一次）

#### 步骤3：采集数据
视频窗口会实时显示相机画面：
- 检测到标定板时显示 **"Board Detected"** 和坐标轴
- 移动机械臂让标定板在相机视野中

**采集操作**：
1. 调整姿态，让相机看到标定板
2. 按 **C** 捕获当前姿态
3. **换一个不同的姿态**（倾斜角度变化越大越好）
4. 重复步骤1-3，采集**至少10张**（推荐30张）
5. 按 **S** 开始标定计算

#### 步骤4：验证结果
标定完成后，检查RMSE：
- **RMSE < 1.5像素** = 标定成功
- RMSE > 1.5像素 = 需要重新标定

### 5.3 标定技巧

| 技巧 | 说明 |
|-----|------|
| 姿态变化要大 | 大角度倾斜比小范围移动更有效 |
| 避免单一平面 | 不要只在一个高度移动 |
| 标定板固定 | 标定板绝对不能移动 |
| 多采集 | 30张比10张精度更高 |

### 5.4 验证标定（可选）
```
主菜单 → 4. 标定 → R. 重投影验证
```

## 6. 传统标定方法

**仅当无法获取URDF文件时使用此方法。**

### 6.1 标定类型说明

| 标定类型 | 作用 | 必要性 |
|---------|------|-------|
| 像素-毫米标定 | 建立像素与实际距离的转换关系 | **必需** |
| XY关节灵敏度标定 | 计算关节转动对画面位移的影响 | **强烈推荐** |
| Z轴关节标定 | 计算关节对末端高度的影响 | 推荐 |

### 6.2 像素-毫米标定

#### 操作步骤
1. 主菜单选择 **4** → 选择 **1** (像素-毫米标定)
2. 系统显示当前画面，确认能看到标记
3. 按 Enter 开始
4. **使用示教器**: 将末端沿 X 方向精确移动 5mm
5. 按 Enter 确认
6. **使用示教器**: 将末端沿 Y 方向精确移动 5mm
7. 按 Enter 确认
8. 系统计算并保存标定结果

### 6.3 XY关节灵敏度标定

1. 主菜单选择 **4** → 选择 **2** (关节灵敏度标定)
2. 对每个关节，使用示教器移动约4度
3. 系统自动计算灵敏度

## 7. 运行对齐

### 7.1 手眼标定对齐（推荐）

```
主菜单 → 8.5 手眼标定对齐
```

操作：
- 按 **A** 开始自动对齐
- 按 **M** 单步对齐
- 按 **Q** 退出

系统会自动：
1. 检测工件和卡槽位置
2. 计算像素偏移 → 世界坐标偏移
3. 移动TCP进行对齐
4. 重复直到误差 < 5像素

### 7.2 传统对齐

```
主菜单 → 8. 运行对齐 (传统灵敏度方法)
```

需要先完成传统标定才能使用。

## 8. 常见问题

### 8.1 标定问题

| 问题 | 可能原因 | 解决方案 |
|-----|---------|---------|
| 标定失败 | 姿态变化不够 | 增加大角度倾斜姿态 |
| RMSE过高 | 标定板移动过 | 重新固定标定板并重做 |
| 检测不到标定板 | 光线/角度问题 | 调整光线和相机角度 |

### 8.2 对齐问题

| 问题 | 可能原因 | 解决方案 |
|-----|---------|---------|
| 对齐方向错误 | 外参矩阵方向问题 | 检查URDF坐标系定义 |
| 深度估计不准 | 双目未标定 | 运行双目基线标定 |
| 标记检测不稳定 | 光线/遮挡 | 改善光照，调整标记位置 |

### 8.3 相机问题

| 问题 | 解决方案 |
|-----|---------|
| 找不到相机 | 检查USB连接，运行 `ls /dev/video*` |
| 画面黑屏 | 检查相机电源和连接 |
| 画面模糊 | 调整相机焦距 |
