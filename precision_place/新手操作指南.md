## 1. 准备工作

### 1.1 硬件准备
- 机器人已通电并正常工作
- 相机已连接（检查USB连接）
- 工件和卡槽已放置在合适位置
- **示教器** 已连接（用于标定时的关节移动）

### 1.2 标记贴纸准备

**重要**: 标记贴纸是系统识别工件和卡槽位置的关键！

| 标记类型 | 颜色 | 数量 | 放置位置 |
|---------|------|------|---------|
| 工件标记 | 绿色 | **3个** | 贴在工件上，呈三角形分布，不能被夹爪遮挡 |
| 卡槽标记 | 红色 | **3个** | 贴在卡槽上，呈三角形分布，靠近定位销 |

**标记要求**:
- 直径约 **1.5-2 厘米** (系统默认15mm)
- 颜色要鲜明、对比度高
- 贴纸要平整，不要起皱
- 三个同色标记呈三角形分布，间距 2-5 cm

**为什么是3个标记？**
```
      ●  ← 标记1 (顶部)
     / \
    ●---●  ← 标记2,3 (底部)

3个标记可以:
1. 计算中心位置 (XY对齐)
2. 计算旋转角度 (旋转对齐)
3. 提高鲁棒性 (单个遮挡仍可工作)
```

### 1.3 光照条件
- 确保工作区域光线充足
- 避免强光直射（会产生反光）
- 避免阴影遮挡标记

```bash

cd /home/smai/dc_dir/lerobot

```

### 2.3 首次运行提示

## 3. 连接设备

### 3.1 选择连接
在主菜单选择 **1** 连接设备

### 3.2 选择手臂
```
选择手臂:
  1. 右手 (默认)
  2. 左手
```
输入 **1** 或 **2** 选择要使用的手臂

### 3.3 选择连接模式

```
连接模式:
  1. 独立模式 (默认) - 直接控制机器人
  2. 示教模式 - 与示教系统协同，只读取状态
```

**推荐选择 2 (示教模式)**，原因：
- 示教程序已连接机器人，独立模式会冲突
- 示教模式下可用示教器精确移动关节
- 通过共享文件读取状态，避免通信冲突
- 标定过程更方便

### 3.4 连接过程
系统会自动连接：
- 机器人（只读取状态）
- 所有相机

**成功标志**:
```
[被动模式] 与示教系统协同工作
  - 只读取机器人状态，不发送控制指令
  - 请确保示教程序已启动 (./run.sh)

✓ 机器人已连接
✓ 主用相机: right_wrist (索引6)
✓ 副用相机: right_wrist2 (索引8)
✓ 使用手臂: right
✓ 模式: 被动模式（与示教协同）
```

## 4. 测试检测

### 4.1 目的
确保相机能正确识别 **6 个标记点**（3个绿色 + 3个红色）

### 4.2 操作步骤
1. 主菜单选择 **3** 测试检测
2. 系统会打开相机画面窗口
3. 观察画面中是否有标记框

### 4.3 画面说明
```
┌─────────────────────────────────────┐
│                                     │
│    ● 绿色圆圈 = 工件标记 (3个)       │
│    ● 红色圆圈 = 卡槽标记 (3个)       │
│    ─ 连线 = 对齐参考线              │
│    △ 三角形 = 姿态估计              │
│                                     │
│  左下角显示:                        │
│  - 检测到的标记数量 (工件/卡槽)     │
│  - 像素误差 (X, Y)                  │
│  - 旋转误差 (度)                    │
│  - 深度估计 (mm)                    │
│                                     │
└─────────────────────────────────────┘
```

### 4.4 退化模式提示
如果标记不足，系统会显示：
```
⚠ 退化模式: 工件2/3, 卡槽1/3
  精度可能降低
```

### 4.5 常见问题排查

| 问题 | 可能原因 | 解决方法 |
|-----|---------|---------|
| 检测不到标记 | 光线太暗/太亮 | 调整光照 |
| 标记时断时续 | 标记被遮挡/太小 | 调整标记位置或更换更大标记 |
| 误检测其他物体 | 背景有相似颜色 | 移除背景干扰物或更换标记颜色 |
| 画面模糊 | 相机焦距不准 | 调整相机焦距 |

### 4.6 调整直到稳定
- 确保画面中显示 **至少 2+2 个标记** (退化模式最低要求)
- 标记检测框稳定不跳动
- 按 **q** 键退出测试

## 5. 标定流程

**重要**: 标定是系统精准控制的关键，必须完成标定后才能使用对齐功能！

### 5.1 标定类型说明

| 标定类型 | 作用 | 必要性 | 精度影响 |
|---------|------|-------|---------|
| 像素-毫米标定 | 建立像素与实际距离的转换关系 | **必需** | 高 |
| XY关节灵敏度标定 | 计算关节转动对画面位移的影响 | **强烈推荐** | 高 |
| Z轴关节标定 | 计算关节对末端高度的影响 | 推荐 | 中 |
| 多姿态标定 | 不同高度下的灵敏度插值 | 可选 | 中 |

### 5.2 像素-毫米标定

#### 操作步骤
1. 主菜单选择 **4** → 选择 **1** (像素-毫米标定)
2. 系统显示当前画面，确认能看到标记
3. 按 Enter 开始
4. **使用示教器**: 将末端沿 X 方向精确移动 5mm
5. 按 Enter 确认
6. **使用示教器**: 将末端沿 Y 方向精确移动 5mm
7. 按 Enter 确认
8. 系统计算并保存标定结果

#### 注意事项
- 移动要精确，建议使用卡尺测量
- 移动方向要与提示一致（X/Y 方向）
- 保持相机画面稳定

### 5.3 XY关节灵敏度标定（推荐）

#### 目的
记录每个关节在不同高度下的灵敏度，系统会根据当前姿态自动选择最合适的标定点。

#### 操作步骤
1. 主菜单选择 **4** → 选择 **2** (关节灵敏度标定)
2. 阅读说明，按 Enter 开始
3. 输入移动角度（默认 **4 度**，直接按 Enter 使用默认值）
4. **对每个关节**（共 4 个关节）:
   ```
   === 关节 7 标定 ===
   [示教模式] 请用示教器将关节 right_arm_joint_1 移动约 4°
     目标角度: 约 XX.XX°
     提示: 移动示教器对应关节，机器人会跟随移动

   [1/3] 采集初始图像...
   [2/3] 移动完成后按 Enter...
   [3/3] 采集移动后图像...

   标定结果:
     实际移动: 4.15°
     像素变化: (30.5, -6.4) pixels
     灵敏度: X=7.35 px/deg, Y=-1.54 px/deg
   ```

5. 完成一个高度后，系统会询问是否在其他高度继续标定

#### XY关节对应关系

**右手关节**:
| 关节索引 | 关节名称 | 示教器对应 | XY控制作用 |
|---------|---------|-----------|-----------|
| 7 | right_arm_joint_1 | 底座旋转 | **X轴主要** |
| 9 | right_arm_joint_3 | 肩部侧摆 | **Y轴主要** |
| 10 | right_arm_joint_4 | 肘部俯仰 | X/Y辅助 |

#### 推荐标定点
建议在 **3 个不同高度** 各做一次标定：
- **高位置**: 卡槽上方约 15 cm
- **中位置**: 卡槽上方约 10 cm
- **低位置**: 卡槽上方约 5 cm

### 5.4 运行全部标定
选择 **4** → **3** 会依次运行像素-毫米标定和关节灵敏度标定

### 5.5 查看标定历史
主菜单选择 **5** 可以查看所有标定记录

## 6. Z轴标定

### 6.1 Z轴控制原理

Z轴控制使用多个关节协调：
```
Z轴控制关节 (按影响从大到小):
  1. joint_1 (底座旋转) - 主要影响
  2. joint_2 (肩部俯仰) - 次要影响
  3. joint_4 (前臂俯仰) - 次要影响
  4. joint_6 (手腕旋转) - 较小影响

注意: 躯干(trunk)只做旋转不做弯腰，不影响末端Z轴
```

### 6.2 深度估计方法

| 方法 | 原理 | 精度 | 要求 |
|-----|------|------|------|
| 双目立体视觉 | 双相机视差 | ±0.5mm | 标记在两个相机视野 |
| 单目尺寸估计 | 已知标记直径 | ±1.5mm | 仅需一个相机 |
| 卡尔曼滤波融合 | 多测量平滑 | ±0.5mm | 多次采样 |

### 6.3 Z轴关节标定

#### 操作步骤
1. 确保已完成双相机基线标定（或使用默认值）
2. 主菜单选择 **4** → **Z轴标定** (如有)
3. 系统会依次标定每个Z轴关节

#### 标定过程
```
=== Z轴关节标定 ===

[关节 7: right_arm_joint_1]
  1. 采集初始深度...
     当前深度: 120.5mm
  2. 请用示教器移动关节 4°
  3. 移动完成后按 Enter...
  4. 采集移动后深度...
     新深度: 152.3mm
     Z变化: 31.8mm
     灵敏度: 7.95 mm/deg
```

### 6.4 双相机基线标定

如果需要更高的Z轴精度，可以标定双相机基线：

#### 自动标定 (推荐)
```python
# 在 Python 中执行
from precision_place import ZAxisController

z_ctrl = ZAxisController()
z_ctrl.set_cameras(camera1, camera2)

# 自动标定 (机器人移动已知距离)
success, baseline = z_ctrl.calibrate_stereo_baseline_auto(
    robot,
    move_distance_mm=20.0
)
```

#### 手动标定
```python
# 使用已知深度
success, baseline = z_ctrl.calibrate_stereo_baseline_manual(
    known_depth_mm=100.0
)
```

### 6.5 相机内参标定 (可选)

更高精度可标定相机内参：

#### 使用标记点
```python
# 快速标定 (无需标定板)
success, intrinsics = z_ctrl.calibrate_camera_intrinsic_with_marker(
    num_samples=10
)
```

#### 使用棋盘格
```python
# 精确标定 (需要棋盘格)
success, intrinsics = z_ctrl.calibrate_camera_intrinsic_opencv(
    chessboard_size=(9, 6),
    square_size_mm=25.0,
    num_images=15
)
```

### 6.6 多姿态标定 (可选)

在不同高度标定关节灵敏度：

```python
# 多高度标定
success = z_ctrl.calibrate_multi_pose_sensitivity(
    robot,
    heights_mm=[80, 120, 160, 200]
)

# 运行时自动插值
sensitivity = z_ctrl.get_interpolated_sensitivity(7, current_height=140)
```

## 7. 预设位置

### 7.1 什么是预设位置
保存机器人的特定姿态（关节角度），方便快速回到关键位置。

### 7.2 保存预设位置
1. 使用示教器将机器人移动到目标位置
2. 主菜单选择 **6** → **1** (保存当前位置)
3. 输入名称，例如: `slot_above`, `home`, `pickup`
4. 系统保存当前所有关节角度

### 7.3 加载预设位置
1. 主菜单选择 **6** → **2** (加载预设位置)
2. 输入之前保存的名称
3. 机器人会自动移动到该位置

### 7.4 推荐预设位置
```
建议保存以下预设位置:
├── home          - 安全起始位置
├── pickup        - 抓取工件位置
├── slot_above    - 卡槽正上方 (用于对齐)
└── slot_final    - 最终放置位置
```

## 8. 运行对齐

### 8.1 快速对齐
主菜单选择 **7**:
1. 将机器人移动到卡槽上方 (5-15 cm)
2. 按 Enter 确认
3. 系统自动调整位置直到对齐
4. 完成后显示最终误差

### 8.2 完整流程
主菜单选择 **8**:
```
[步骤1] 抓取工件
  → 请手动抓取，完成后按 Enter...

[步骤2] 移动到卡槽上方
  → 请移动到大致位置，完成后按 Enter...

[步骤3] 自动对齐
  → 系统自动调整 X/Y 位置
  → 显示实时误差和调整

[步骤4] 放置
  → 询问是否自动放置 (y/n)

[步骤5] 撤退
  → 自动或手动抬起

完成! 显示耗时和对齐结果
```

### 8.3 对齐过程显示
```
[对齐 5/30]
  工件: 3/3, 卡槽: 3/3
  当前偏移: (12.3, -5.6) px
  位置误差: (1.85, 0.84)mm, 总: 2.03mm
  旋转误差: 1.25deg
  深度: 125.3mm

  位置调整: {7: 0.15°, 9: -0.08°, 10: 0.02°}
```

### 8.4 退化模式下的对齐
如果标记不足，系统自动进入退化模式：
```
⚠ 退化模式: 工件2/3, 卡槽2/3
  精度可能降低 (标记不足)
  位置误差: (2.15, 1.32)mm, 总: 2.52mm
```

### 8.5 对齐精度说明
- **tolerance_mm = 2.0**: 默认精度要求 2mm
- **退化模式**: 自动放宽到 3mm
- 对齐成功条件: X 和 Y 误差都小于容差

## 9. 常见问题

### Q1: 检测不到标记怎么办？
1. 检查光照是否充足
2. 确认标记颜色正确（绿色=工件，红色=卡槽）
3. 调整相机角度和高度
4. 尝试更换更大/更鲜艳的标记
5. 检查是否需要3个标记（三角形分布）

### Q2: 对齐不准确怎么办？
1. 重新运行像素-毫米标定
2. 运行关节灵敏度标定（如果还没做）
3. 确保在多个高度都做了标定
4. 检查标记是否贴牢、是否平整
5. 检查双相机是否都正常工作

### Q3: Z轴深度不准确？
1. 检查标记直径设置是否正确（默认15mm）
2. 运行双相机基线标定
3. 确保标记在两个相机视野中
4. 考虑标定相机内参

### Q4: 示教模式下连接失败？
1. 确认示教程序已启动 (./run.sh)
2. 如果机器人连接失败但相机正常，程序会继续运行
3. 在仅相机模式下，标定仍可进行（无法读取实际角度）

### Q5: 关节标定时移动方向不确定？
- 移动示教器对应关节，观察机器人动作
- 正负方向都可以，系统会自动计算
- 重要的是移动角度要准确（观察示教器显示）

### Q6: 如何切换左右手？
1. 主菜单选择 **2**
2. 选择要切换的手臂
3. 系统会自动切换相机配置

### Q7: 标定数据存在哪里？
- `calibration_history.json` - 像素-毫米标定历史
- `calibration_points.json` - XY关节灵敏度标定点
- `z_axis_calibration.json` - Z轴标定数据
- `multi_pose_calibration.json` - 多姿态标定数据
- `presets.json` - 预设位置

### Q8: 如何重新标定？
直接再次运行标定即可，新数据会追加到历史记录中。系统会使用最新的标定数据。

### Q9: 退化模式是什么？
当标记被遮挡或不足时，系统自动进入退化模式：
- 最低要求: 工件1个 + 卡槽1个标记
- 精度降低到 ±3mm
- 跳过旋转校正
- 使用历史偏移预测

### Q10: 双相机如何工作？
```
主相机 (right_wrist):
  - 主要检测点
  - 工件标记检测（工件在夹爪上，主相机更稳定）

副相机 (right_wrist2):
  - 辅助检测卡槽标记
  - 与主相机融合提供深度估计
```
