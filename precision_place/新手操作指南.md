## 1. 准备工作

### 1.1 硬件准备
- 机器人已通电并正常工作
- 相机已连接（检查USB连接）
- 工件和卡槽已放置在合适位置
- **示教器** 已连接（用于标定时的关节移动）

### 1.2 标记贴纸准备

**重要**: 标记贴纸是系统识别工件和卡槽位置的关键！

| 标记类型 | 颜色 | 数量 | 放置位置 |
|---------|------|------|---------|
| 工件标记 | 绿色 | 2个 | 贴在工件上，靠近定位孔，不能被夹爪遮挡 |
| 卡槽标记 | 红色 | 2个 | 贴在卡槽上，靠近定位销 |

**标记要求**:
- 直径约 1-2 厘米
- 颜色要鲜明、对比度高
- 贴纸要平整，不要起皱
- 两个同色标记要有一定间距（建议 2-5 cm）

### 1.3 光照条件
- 确保工作区域光线充足
- 避免强光直射（会产生反光）
- 避免阴影遮挡标记

## 2. 启动系统

### 2.1 启动示教程序（推荐）

**重要**: 标定时需要移动机器人关节，推荐使用示教模式。

```bash
# 终端1：启动示教程序
cd /home/smai/dc_dir
./run.sh
```

等待示教程序启动完成，看到以下信息后示教器即可控制机器人：
```
✓ 机器人状态共享已启用 (标定程序可读取)
```

**状态共享**: 示教程序会周期性写入机器人状态到共享文件，标定程序通过读取该文件获取关节位置，

### 2.2 启动精准放置程序

```bash
# 终端2：启动精准放置程序
cd /home/smai/dc_dir/lerobot
python precision_place/run.py
```

### 2.3 首次运行提示
如果是首次运行，系统会显示欢迎引导界面，按 **Enter** 继续。

## 3. 连接设备

### 3.1 选择连接
在主菜单选择 **1** 连接设备

### 3.2 选择手臂
```
选择手臂:
  1. 右手 (默认)
  2. 左手
```
输入 **1** 或 **2** 选择要使用的手臂

### 3.3 选择连接模式

```
连接模式:
  1. 独立模式 (默认) - 直接控制机器人
  2. 示教模式 - 与示教系统协同，只读取状态
```

**推荐选择 2 (示教模式)**，原因：
- 示教程序已连接机器人，独立模式会冲突
- 示教模式下可用示教器精确移动关节
- 通过共享文件读取状态，避免通信冲突
- 标定过程更方便

### 3.4 连接过程
系统会自动连接：
- 机器人（只读取状态）
- 所有相机

**成功标志**:
```
[被动模式] 与示教系统协同工作
  - 只读取机器人状态，不发送控制指令
  - 请确保示教程序已启动 (./run.sh)

✓ 机器人已连接
✓ 主用相机: right_wrist2 (索引8)
✓ 使用手臂: right
✓ 模式: 被动模式（与示教协同）
```

## 5. 标定

**重要**: 标定是系统精准控制的关键，必须完成标定后才能使用对齐功能！

### 5.1 标定类型说明

| 标定类型 | 作用 | 必要性 |
|---------|------|-------|
| 像素-毫米标定 | 建立像素与实际距离的转换关系 | 必需 |
| 关节灵敏度标定 | 计算每个关节转动1度对应画面移动多少像素 | 强烈推荐 |

### 5.2 像素-毫米标定

#### 操作步骤
1. 主菜单选择 **4** → 选择 **1** (像素-毫米标定)
2. 系统显示当前画面，确认能看到 4 个标记
3. 按 Enter 开始
4. **使用示教器**: 将末端沿 X 方向精确移动 5mm
5. 按 Enter 确认
6. **使用示教器**: 将末端沿 Y 方向精确移动 5mm
7. 按 Enter 确认
8. 系统计算并保存标定结果

#### 注意事项
- 移动要精确，建议使用卡尺测量
- 移动方向要与提示一致（X/Y 方向）
- 保持相机画面稳定

### 5.3 关节灵敏度标定（推荐）

#### 目的
记录每个关节在不同高度下的灵敏度，系统会根据当前姿态自动选择最合适的标定点。

#### 操作步骤
1. 主菜单选择 **4** → 选择 **2** (关节灵敏度标定)
2. 阅读说明，按 Enter 开始
3. 输入移动角度（默认 2 度，直接按 Enter 使用默认值）
4. **对每个关节**（共 4 个关节）:
   ```
   === 关节 7 标定 ===
   [示教模式] 请用示教器将关节 right_arm_joint_1 移动约 2°
     目标角度: 约 XX.XX°
     提示: 移动示教器对应关节，执行机器人会跟随移动

   [1/3] 采集初始图像...
   [2/3] 移动完成后按 Enter...
   [3/3] 采集移动后图像...

   标定结果:
     实际移动: 2.15°
     像素变化: (15.3, -3.2) pixels
     灵敏度: X=7.12 px/deg, Y=-1.49 px/deg
   ```

5. 完成一个高度后，系统会询问是否在其他高度继续标定

#### 示教器关节对应关系

**右手关节**:
| 关节索引 | 关节名称 | 示教器对应 | 作用 |
|---------|---------|-----------|------|
| 7 | right_arm_joint_1 | 底座旋转 | 水平旋转 |
| 8 | right_arm_joint_2 | 肩部俯仰 | 高度调节 |
| 9 | right_arm_joint_3 | 肩部侧摆 | 侧向移动 |
| 10 | right_arm_joint_4 | 肘部俯仰 | 前后移动 |

#### 推荐标定点
建议在 **3 个不同高度** 各做一次标定：
- **高位置**: 卡槽上方约 15 cm
- **中位置**: 卡槽上方约 10 cm
- **低位置**: 卡槽上方约 5 cm

### 5.4 运行全部标定
选择 **4** → **3** 会依次运行两种标定

### 5.5 查看标定历史
主菜单选择 **5** 可以查看所有标定记录

## 6. 预设位置

### 6.1 什么是预设位置
保存机器人的特定姿态（关节角度），方便快速回到关键位置。

### 6.2 保存预设位置
1. 使用示教器将机器人移动到目标位置
2. 主菜单选择 **6** → **1** (保存当前位置)
3. 输入名称，例如: `slot_above`, `home`, `pickup`
4. 系统保存当前所有关节角度

### 6.3 加载预设位置
1. 主菜单选择 **6** → **2** (加载预设位置)
2. 输入之前保存的名称
3. 机器人会自动移动到该位置

### 6.4 推荐预设位置
```
建议保存以下预设位置:
├── home          - 安全起始位置
├── pickup        - 抓取工件位置
├── slot_above    - 卡槽正上方 (用于对齐)
└── slot_final    - 最终放置位置
```

## 7. 运行对齐

### 7.1 快速对齐
主菜单选择 **7**:
1. 将机器人移动到卡槽上方 (5-10 cm)
2. 按 Enter 确认
3. 系统自动调整位置直到对齐
4. 完成后显示最终误差

### 7.2 完整流程
主菜单选择 **8**:
```
[步骤1] 抓取工件
  → 请手动抓取，完成后按 Enter...

[步骤2] 移动到卡槽上方
  → 请移动到大致位置，完成后按 Enter...

[步骤3] 自动对齐
  → 系统自动调整 X/Y 位置

[步骤4] 放置
  → 询问是否自动放置 (y/n)

[步骤5] 撤退
  → 自动或手动抬起

完成! 显示耗时和对齐结果
```

### 7.3 对齐精度说明
- **tolerance_mm = 2.0**: 默认精度要求 2mm
- 对齐成功条件: X 和 Y 误差都小于 2mm
- 系统会持续调整直到达到精度或超过最大迭代次数

## 8. 常见问题

### Q1: 检测不到标记怎么办？
1. 检查光照是否充足
2. 确认标记颜色正确（绿色=工件，红色=卡槽）
3. 调整相机角度和高度
4. 尝试更换更大/更鲜艳的标记

### Q2: 对齐不准确怎么办？
1. 重新运行像素-毫米标定
2. 运行关节灵敏度标定（如果还没做）
3. 确保在多个高度都做了标定
4. 检查标记是否贴牢、是否平整

### Q3: 示教模式下连接失败？
1. 确认示教程序已启动 (./run.sh)
2. 如果机器人连接失败但相机正常，程序会继续运行
3. 在仅相机模式下，标定仍可进行（无法读取实际角度）

### Q4: 关节标定时移动方向不确定？
- 移动示教器对应关节，观察机器人动作
- 正负方向都可以，系统会自动计算
- 重要的是移动角度要准确（观察示教器显示）

### Q5: 如何切换左右手？
1. 主菜单选择 **2**
2. 选择要切换的手臂
3. 系统会自动切换相机配置

### Q6: 标定数据存在哪里？
- `calibration_history.json` - 像素-毫米标定历史
- `calibration_points.json` - 关节灵敏度标定点
- `presets.json` - 预设位置

### Q7: 如何重新标定？
直接再次运行标定即可，新数据会追加到历史记录中。系统会使用最新的标定数据。

```
  关节 2 (shoulder_pitch)   : 肩部俯仰
  关节 3 (shoulder_roll)    : 肩部侧摆
  关节 4 (elbow_pitch)      : 肘部俯仰
  关节 5 (elbow_roll)       : 肘部旋转
  关节 6 (wrist_pitch)      : 腕部俯仰
```

### 5.4 运行全部标定
选择 **4** → **3** 会依次运行两种标定

### 5.5 查看标定历史
主菜单选择 **5** 可以查看所有标定记录

## 6. 预设位置

### 6.1 什么是预设位置
保存机器人的特定姿态（关节角度），方便快速回到关键位置。

### 6.2 保存预设位置
1. 使用示教器将机器人移动到目标位置
2. 主菜单选择 **6** → **1** (保存当前位置)
3. 输入名称，例如: `slot_above`, `home`, `pickup`
4. 系统保存当前所有关节角度

### 6.3 加载预设位置
1. 主菜单选择 **6** → **2** (加载预设位置)
2. 输入之前保存的名称
3. 机器人会自动移动到该位置

### 6.4 推荐预设位置
```
建议保存以下预设位置:
├── home          - 安全起始位置
├── pickup        - 抓取工件位置
├── slot_above    - 卡槽正上方 (用于对齐)
└── slot_final    - 最终放置位置
```

## 7. 运行对齐

### 7.1 快速对齐
主菜单选择 **7**:
1. 将机器人移动到卡槽上方 (5-10 cm)
2. 按 Enter 确认
3. 系统自动调整位置直到对齐
4. 完成后显示最终误差

### 7.2 完整流程
主菜单选择 **8**:
```
[步骤1] 抓取工件
  → 请手动抓取，完成后按 Enter...

[步骤2] 移动到卡槽上方
  → 请移动到大致位置，完成后按 Enter...

[步骤3] 自动对齐
  → 系统自动调整 X/Y 位置

[步骤4] 放置
  → 询问是否自动放置 (y/n)

[步骤5] 撤退
  → 自动或手动抬起

完成! 显示耗时和对齐结果
```

### 7.3 对齐精度说明
- **tolerance_mm = 2.0**: 默认精度要求 2mm
- 对齐成功条件: X 和 Y 误差都小于 2mm
- 系统会持续调整直到达到精度或超过最大迭代次数

## 8. 常见问题

### Q1: 检测不到标记怎么办？
1. 检查光照是否充足
2. 确认标记颜色正确（绿色=工件，红色=卡槽）
3. 调整相机角度和高度
4. 尝试更换更大/更鲜艳的标记

### Q2: 对齐不准确怎么办？
1. 重新运行像素-毫米标定
2. 运行关节灵敏度标定（如果还没做）
3. 确保在多个高度都做了标定
4. 检查标记是否贴牢、是否平整

### Q3: 关节标定时移动方向不确定？
- 可以先小幅度移动观察画面变化
- 正负方向都可以，系统会自动计算
- 重要的是移动角度要准确（使用示教器显示）

### Q4: 如何切换左右手？
1. 主菜单选择 **2**
2. 选择要切换的手臂
3. 系统会自动切换相机配置

### Q5: 标定数据存在哪里？
- `calibration_history.json` - 像素-毫米标定历史
- `calibration_points.json` - 关节灵敏度标定点
- `presets.json` - 预设位置

### Q6: 如何重新标定？
直接再次运行标定即可，新数据会追加到历史记录中。系统会使用最新的标定数据。
